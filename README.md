# Real-Time Object Detection & Counting (YOLOv8 + OpenCV)

Детекция, трекинг и подсчёт объектов на видео в реальном времени.
Объекты считаются при пересечении заданной линии — классическая задача
для систем видеоаналитики (подсчёт посетителей, машин на въезде/выезде и т.д.).

## Возможности

- Детекция объектов через YOLOv8 (COCO-классы «из коробки», либо своя дообученная модель)
- Трекинг с сохранением ID между кадрами (ByteTrack, встроен в ultralytics)
- Подсчёт пересечений линии отдельно "вход" / "выход"
- Фильтрация по нужным классам (например, только `person` и `car`)
- Сохранение результата в видеофайл
- Вывод FPS и статистики в реальном времени

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
# Веб-камера
python object_counter.py --source 0

# Видеофайл, только люди и машины
python object_counter.py --source input.mp4 --classes person car

# С сохранением результата
python object_counter.py --source input.mp4 --save output.mp4 --conf 0.5
```

## Как это работает

1. Каждый кадр прогоняется через YOLOv8 в режиме трекинга (`model.track`),
   что даёт не только bounding box'ы, но и устойчивый ID объекта между кадрами.
2. Для каждого трек-ID сохраняется предыдущая координата Y центра рамки.
3. Если центр объекта пересёк заданную горизонтальную линию — засчитывается
   вход (сверху вниз) или выход (снизу вверх), причём каждый ID считается
   только один раз.

## Возможные доработки

- Замена YOLOv8n на дообученную модель под свой домен (например, товары на полке)
- Подсчёт по нескольким линиям / зонам одновременно
- Веб-интерфейс на Streamlit с загрузкой видео и отображением графика подсчёта во времени
- Экспорт статистики в CSV/JSON для дальнейшего анализа

## Метрики (пример для отчёта в резюме/портфолио)

При заполнении реальными результатами укажите здесь:
- FPS на вашем железе (CPU/GPU)
- Точность подсчёта на тестовом видео (сравнение с ручной разметкой)
- Использованный размер модели (n/s/m/l/x) и trade-off скорость/точность
